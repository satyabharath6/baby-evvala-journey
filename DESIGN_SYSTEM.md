# 🎨 Baby Evvala Design System

## Design Principle

Technology should stay invisible. Emotion should stay visible.

## Visual Style

Elegant  
Warm  
Premium  
Cinematic  
Emotional  
Mobile-first  

## Colors

Midnight: #0B1020  
Deep Purple: #6D3BF5  
Rose Pink: #FF5FA2  
Warm Gold: #F7D774  
White: #FFFFFF  
Soft White: #E5E7EB  
Muted: #B8C0CC  

## Glass Card

Use this pattern for cards:

background: rgba(255,255,255,.08)  
backdrop-filter: blur(16px)  
border: 1px solid rgba(255,255,255,.15)  
border-radius: 24px  

## Buttons

Primary button:
Pink to purple gradient  
Rounded pill  
Soft glow  
No harsh animation  

Secondary button:
Transparent glass  
White border  
Soft hover  

## Typography

Hero: 3rem–5.5rem  
Section title: 2rem–3rem  
Body: 1rem  
Line height: 1.7–1.8  

## Motion

Fade: 0.6–0.8s  
Hover: 0.25–0.35s  
Float: 6–10s  
Heartbeat: 2.4s  

Animations must feel calm, not busy.

## Mobile Rule

Design for phones first.  
Desktop should enhance the experience, not define it.

## Feature Rule

Every feature must make the site:

- More meaningful
- More beautiful
- More memorable

Otherwise, do not build it.
